# Snappymob Application Programming Challenge

## By Haseeb Ghaffar

## Overview

Kindly run below command in a sequence this is important to get desired output files

## Commands

```bash
# Install node_modules
npm i
OR
yarn install
# 1st command
# To test Challenge A run this command
$ npm run start:a

# 2nd command
# You must build docker file run this command
$ npm run docker:build

# 3rd command
# To test Challenge B run this or you can also run `node challengeB.js` in terminal
$ npm run docker:up

# 4th command if needed to restart docker
# To restart container run
$ npm run docker:rs

# 5th command
# In last run
$ npm run docker:rm
```
